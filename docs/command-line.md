# 11. Командная строка

Программа обрабатывает **только первый аргумент**. Примеры для PowerShell:

```powershell
# Открыть подключение по отображаемому имени из списка
.\SmarTTY.exe "user@server.example.com"

# То же самое по паре user@host, как у ssh: сначала ищется запись с этим пользователем и хостом,
# затем любая запись к этому хосту (порт в поле хоста не мешает)
.\SmarTTY.exe "root@10.0.0.5"

# Загрузить XML-профиль SSH из файла
.\SmarTTY.exe "/ssh:C:\Profiles\server.sshconnection"

# Загрузить XML-задание с настройками SSH и начальной командой
.\SmarTTY.exe "/job:C:\Profiles\maintenance.xml"

# Открыть Telnet-подключение без сохранения (порт по умолчанию — 23)
.\SmarTTY.exe "/telnet:192.168.1.1"
.\SmarTTY.exe "/telnet:router.local:2323"

# Telnet поверх TLS (порт по умолчанию — 992)
.\SmarTTY.exe "/telnets:switch.local"

# Приёмник netconsole без сохранения: порт 6666, ввод — последнему отправителю
.\SmarTTY.exe "/netconsole"
# другой порт; адрес устройства для ввода; порт@устройство:порт
.\SmarTTY.exe "/netconsole:7777"
.\SmarTTY.exe "/netconsole:192.168.1.20"
.\SmarTTY.exe "/netconsole:6666@192.168.1.20:6666"
```

Для первого варианта профиль уже должен присутствовать в списке. Аргумент `user@host` (как у `ssh`) сначала сравнивается с отображаемым именем записи, а если точного совпадения нет — ищется сохранённое подключение с таким пользователем и хостом, а затем любое подключение к этому хосту (порт в поле хоста при этом не учитывается). Это по-прежнему не произвольное SSH-подключение: пароль, ключ и прочие параметры берутся из найденного профиля, а не из аргумента.

Префиксы `/ssh:`, `/job:`, `/telnet:`, `/telnets:` и `/netconsole` не зависят от регистра. После `/netconsole:` указывается локальный порт, адрес устройства (`host`, `host:port`, `[ipv6]:port`) или `порт@host[:port]`. После `/telnet:` и `/telnets:` указывается `host`, `host:port` или `[ipv6]:port` (для `/telnets:` порт по умолчанию — 992, включается TLS); для `/ssh:` и `/job:` — путь; специальное расширение job-файла не требуется. Задание — XML модели `SmarTTYJob` с полями `Settings` (параметры `SSHConnectionSettings`), `Command` и `EchoInitialCommand`. Произвольные JSON, shell-скрипты или обычный SSH config здесь не поддерживаются. Загружайте задания только из доверенных источников: они могут выполнять команды на сервере.
