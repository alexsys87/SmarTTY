# 9. Настройки и горячие клавиши

Для SSH-интерфейса откройте **Tools → Settings**:

| Раздел | Что настраивается |
| --- | --- |
| **Common Settings** | Папки передачи файлов, буфер обмена, действия `Alt+буква`, колеса мыши и `Shift+PageUp/PageDown`, дополнительные сочетания клавиш, байтовый режим обычного терминала SSH (BusyBox на OpenWrt) |
| **Paste Settings** | Безопасная вставка: удаление управляющих символов и escape-последовательностей, замена «умных» кавычек и тире, завершающий перевод строки, перевод строки вставляемого текста, предупреждения о многострочной вставке и об опасных командах |
| **Visual Settings** | Тема, расположение вкладок, полосы прокрутки, моноширинный шрифт, цвета, сигнал BEL, обработка больших блоков текста; группа **X Server**: какой X-сервер запускать (**Ask on first use**, VcXsrv или свой), его аргументы (по умолчанию `-multiwindow`), найден ли VcXsrv и кнопка **Download latest VcXsrv...**. Сама пересылка X11 включается в профиле подключения (раздел 2) |
| **Editor Settings** | Цвета редактора и подсветки синтаксиса (с кнопкой сброса), размер табуляции, отступ пробелами, удалённый временный каталог, включение подсветки, подчёркивание табов, автодополнение (в том числе автоматическое во время набора) |
| **Smart Terminal Settings** | Тип терминала, shell, файловая панель, ссылки на файлы, автодополнение и байтовый режим для запускаемых программ |

Окно настроек всегда одного размера: разделы отличаются числом настроек, поэтому содержимое длинной вкладки (например, **Paste Settings**) прокручивается внутри окна, а высота окна при переключении вкладок не меняется.

**View → Auto-wrap lines**, **Close tab when shell exits**, **Minimalistic mode** и **Full-screen mode** управляют видом главного окна. В минималистичном режиме для доступа к меню наведите указатель к верхнему краю окна.

| Сочетание | Действие и условия |
| --- | --- |
| `Alt+Enter` | Переключение полноэкранного режима в терминале SSH |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Переключение страниц текущего SSH-сеанса |
| `Ctrl+W` | Закрыть терминальную вкладку, если включено **Close tab on Ctrl+W, new tab on Ctrl+Shift+T** |
| `Ctrl+Shift+T` | Новая обычная терминальная вкладка при той же настройке |
| `Tab`, `Ctrl+Space` | Дополнение в Smart Terminal; `Ctrl+Space` зависит от настроек триггера |
| `↑` / `↓`, `Ctrl+R`, `Ctrl+Shift+R` | История при редактировании строки в Smart Terminal: перебор (при набранном тексте — только команды с таким началом), поиск как в bash (`Ctrl+R`/`Ctrl+S`, `Esc` — отмена), список |
| `→` / `End`, `Ctrl+→`, `Esc` | Серая подсказка из истории в конце строки Smart Terminal и COM/TCP-терминала: подставить целиком, подставить следующее слово, скрыть |
| `Ctrl+C`, `Ctrl+D`, `Ctrl+L`, `Ctrl+U` / `Ctrl+K` | В строке Smart Terminal: копирование выделения (без выделения — очистка строки), закрытие вкладки на пустой строке, очистка экрана, удаление до начала / конца строки |
| `Ctrl+S`, `Ctrl+O` | Сохранить / открыть удалённый файл, когда фокус в редакторе |
| `Ctrl+F`, `F3` / `Shift+F3` | Поиск и следующее / предыдущее совпадение в редакторе |
| `Ctrl+H`, `Ctrl+G` | Замена (Enter в поле замены — заменить и найти следующее) и переход к строке (`120` или `120:5`) в редакторе |
| `Ctrl+Shift+C` | Копирование в текстовом COM/TCP-терминале; `Ctrl+C` отправляется устройству |
| `Ctrl`/`Alt`/`Shift` + стрелки, `Home`, `End`, `PageUp/Down`, `F1`–`F12` | В обычном терминале отправляются в формате xterm (`Ctrl+←` = `ESC [ 1 ; 5 D`): переход по словам в bash, vim, tmux |
| `Shift+Tab`, `Ctrl+Space`, `Alt+цифра` | В обычном терминале: back-tab (`ESC [ Z`), NUL (установка метки в Emacs/readline), `ESC` + цифра (при включённой отправке `Alt+буква` в сеанс) |
| `Shift` + мышь | Локальное выделение текста, даже когда программа перехватывает мышь |

Универсальные команды копирования, вставки и поиска также доступны в меню **Edit** SSH-окна. По умолчанию выделенный текст автоматически копируется; поведение меняется в **Common Settings**. Если включён перехват `Ctrl+C/Ctrl+X/Ctrl+V` для буфера обмена, `Ctrl+C` может перестать отправлять удалённой программе сигнал прерывания. Учитывайте текущие настройки, а не только привычные сочетания.

## 10. Хранение настроек и portable-режим

Настройки хранятся в **XML, не INI**.

| Данные | Обычное расположение |
| --- | --- |
| Основные настройки | `%APPDATA%\SmarTTY\Settings.xml` |
| Доверенные ключи серверов | `%APPDATA%\SmarTTY\KnownHosts.xml` |
| SSH-профили | `%APPDATA%\SmarTTY\SavedConnections\*.sshconnection` |
| COM/TCP-профили | `%APPDATA%\SmarTTY\SavedConnections\*.rawconnection` |
| Параметры интерфейса и окна выбора подключений | `%LOCALAPPDATA%\SmarTTY\GUIPreferences.xml` |
| Настройки TFTP-сервера / загрузки U-Boot | `%LOCALAPPDATA%\SmarTTY\TftpFirmware.xml` |
| Быстрые команды и скрипты (Tools → Quick commands) | `%APPDATA%\SmarTTY\QuickCommands.xml` |
| База автодополнения команд | `CommandCompletions.xml` или сжатый `CommandCompletions.xml.gz` рядом с `SmarTTY.exe` (необязательный файл; ищется сначала рядом с программой, затем в `%APPDATA%\SmarTTY`, пока его нет нигде, используется шаблон, встроенный в программу) |

Чтобы включить portable-режим, закройте программу и создайте пустой **`portable.txt` рядом с `SmarTTY.exe`**. После следующего запуска основные настройки, ключи доверенных серверов и профили будут читаться из **`PortableSettings`** рядом с приложением. Для переноса существующих данных скопируйте туда содержимое `%APPDATA%\SmarTTY` до запуска; автоматическая миграция не предусмотрена. Каталог программы должен быть доступен для записи.

**Portable не означает полную автономность:** `GUIPreferences.xml` остаётся в `%LOCALAPPDATA%`, а ключи SmarTTY и защита сохранённых паролей используют криптографические контейнеры пользователя Windows. Копирование одной папки с настройками не переносит эти контейнеры на другой компьютер. Для OpenSSH-профиля также отдельно переносится приватный ключ и проверяется путь к нему.

**Редактор автодополнений.** Пункт **Tools → Command completions...** открывает окно для правки `CommandCompletions.xml`: список команд слева (с поиском, кнопками New / Duplicate / Delete), справа поля команды (имя, описание, необязательное регулярное выражение для всей командной строки, запрет автоматического показа) и список её опций (значение, другие написания через `|`, краткое и подробное описание, порядок Up / Down). Поле **Try** показывает, сработает ли запись для введённой командной строки (например, `ls -`). Перед сохранением проверяются пустые команды и опции, которые загрузчик молча отбросил бы, и неверные регулярные выражения. Флажок **Save compressed** сохраняет базу как `CommandCompletions.xml.gz` (gzip, его SmarTTY читает сам); второй вариант файла при сохранении удаляется, потому что обычный XML имеет приоритет. Новые подсказки используют сохранённые изменения сразу, без перезапуска. Если файл повреждён, редактор предлагает открыть пустой список и не перезаписывает файл без подтверждения. Пока рядом с `SmarTTY.exe` нет файла, SmarTTY использует базу, встроенную в программу, и ничего не создаёт на диске; файл рядом с программой, если он есть, имеет приоритет над файлом в `%APPDATA%\SmarTTY`. Редактор открывает встроенную базу, а при первом сохранении записывает её вместе с вашими правками в `CommandCompletions.xml` рядом с программой, и дальше работает с этим файлом. Если папка программы защищена от записи (например, `Program Files`), при первом сохранении файл создаётся в `%APPDATA%\SmarTTY` и читается оттуда при запуске; позднее появившийся файл рядом с программой снова получает приоритет.

**Импорт и экспорт настроек.** Ссылки **Import settings...** и **Export settings...** в окне выбора подключений, а также кнопки внизу слева в окне **Settings** сохраняют выбранные файлы в один архив `.tar.gz` и восстанавливают их из архива. Это обычный tar внутри gzip: архив открывают 7-Zip и `tar -xzf`. Состав архива:

```
Settings.xml
KnownHosts.xml
QuickCommands.xml        (быстрые команды и скрипты меню терминала)
SavedConnections/*.sshconnection
SavedConnections/*.rawconnection
Local/GUIPreferences.xml
Local/TftpFirmware.xml   (настройки окна TFTP-сервера / загрузки U-Boot)
CommandCompletions.xml   (или CommandCompletions.xml.gz, если SmarTTY использует сжатый файл)
Keys/SmarTTY-ssh-key.xml
Keys/SmarTTY-ssh-key-ed25519, -ecdsa-nistp256, -ecdsa-nistp384, -ecdsa-nistp521
Keys/SmarTTY-password-key.xml
OpenSSH/id_ed25519, id_ed25519.pub, id_ecdsa, id_ecdsa.pub, id_rsa, id_rsa.pub
```

- **Окно выбора.** Перед экспортом и перед импортом открывается окно с флажками: основные настройки, доверенные ключи серверов, параметры интерфейса, настройки TFTP-сервера / загрузки U-Boot (`TftpFirmware.xml`), быстрые команды и скрипты (`QuickCommands.xml`), SSH-профили, COM/TCP/Telnet-профили, сохранённые пароли в профилях, `CommandCompletions.xml`, а в группе **Authentication keys** — ключ SmarTTY для входа по публичному ключу, ключ защиты паролей и ключи OpenSSH из `.ssh`. Недоступные пункты (нет на этом компьютере при экспорте, нет в архиве при импорте) отключены. По умолчанию отмечены настройки, профили, настройки TFTP, быстрые команды и `CommandCompletions.xml`; пароли и ключи нужно отметить самому. Нетронутые пункты при импорте не меняются.
- **Сохранённые пароли.** По умолчанию они не включаются: пароли зашифрованы ключом пользователя Windows и на другом компьютере не расшифруются. Чтобы они заработали на новом компьютере, экспортируйте и импортируйте вместе с ними **ключ защиты паролей** (`Keys/SmarTTY-password-key.xml`). Импорт этого ключа заменяет текущий: пароли, сохранённые на этом компьютере и не пришедшие из архива, перестанут расшифровываться. Если при импорте профилей пункт про пароли не отмечен, пароли из архива отбрасываются, а локальные сохраняются.
- **Ключи.** Ключи SmarTTY RSA лежат в криптографических контейнерах пользователя Windows; в архив они попадают как XML `RSAParameters` (тот же формат, что у файлов `*.sshkey` в **Import key / Export key**). Ключи Ed25519 и ECDSA, которые есть на компьютере, входят в тот же пункт «ключ SmarTTY» и попадают в архив как приватные ключи OpenSSH (`Keys/SmarTTY-ssh-key-ed25519` и т. д.). Из `.ssh` берутся только файлы `id_ed25519`, `id_ecdsa`, `id_rsa` и их `.pub`; `known_hosts` и `config` не трогаются. **Приватные ключи и пароли в архиве не шифруются:** храните такой архив как секрет и удаляйте, когда он не нужен.
- `CommandCompletions.xml` заменяется целиком и применяется после перезапуска. Если база хранится сжатой (`CommandCompletions.xml.gz`, когда обычного файла нет), в архив попадает именно она, а при импорте файл создаётся в той же форме, что в архиве; вторая форма удаляется, потому что обычный XML имеет приоритет над gz. Если каталог программы защищён от записи (например, `Program Files`), файл записывается в `%APPDATA%\SmarTTY`.
- Импорт сначала проверяет весь архив: допустимы только перечисленные имена файлов, содержимое должно быть корректным XML нужного типа, размер ограничен. Если проверка не пройдена, ничего не записывается.
- Перед записью текущие настройки и всё, что заменяют выбранные ключи и `CommandCompletions.xml`, сохраняются в `Backups\before-import-<дата>.tar.gz` внутри каталога настроек (при portable-режиме это `PortableSettings`). Если среди заменяемых есть ключи, резервная копия тоже содержит их без шифрования.
- Файлы с совпадающими именами заменяются, остальные сохранённые подключения остаются. Если у SSH-профиля в архиве нет пароля, а локально он сохранён, локальный пароль не удаляется. То же относится к паролю автоматического входа в Telnet-профилях: он не попадает в экспорт без паролей, а локальный сохранённый пароль не затирается импортом профиля без пароля.
- Файлы ключей, на которые профили ссылаются явным путём (**Override default key location**), в архив не входят: переносите их отдельно и проверьте путь в профиле.
- `GUIPreferences.xml` полностью применяется после перезапуска программы.

Перед ручным изменением XML закройте SmarTTY и сделайте копию файлов. Некоторые ошибки загрузки и сохранения настроек в текущем коде подавляются: если изменения исчезают, проверьте права записи, свободное место и корректность XML.
