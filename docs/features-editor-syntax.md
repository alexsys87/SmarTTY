# Редактор: подсветка и автодополнение

На странице: [подсветка синтаксиса](#подсветка-синтаксиса) · [автодополнение](#автодополнение) · [база символов API](#база-символов-api) · [подсказка параметров](#подсказка-параметров).

## Подсветка синтаксиса

Редактор подсвечивает синтаксис для Python, shell, PowerShell, конфигурационных файлов, C-подобных языков, Makefile/CMake/Meson, HCL, Starlark, Nix, Fish, Batch, Dockerfile, Ruby/Perl, SQL/Lua, HTML/XML, Markdown и diff; язык определяется по расширению, а при его отсутствии — по shebang. Подсветка включается и выключается в **Editor Settings**.

### Как выбирается язык

Язык выбирается автоматически: по имени файла, по пути (`/etc/config/*` — UCI; `/boot/config-*` — Kconfig; `/etc/init.d/`, `/etc/hotplug.d/`, `/etc/uci-defaults/` — shell) и по строке `#!` (`#!/bin/sh /etc/rc.common`, `#!/usr/bin/lua`, `#!/usr/bin/env python3`).

**Вручную.** Кнопка с названием языка в строке состояния редактора (слева от кодировки) — «Detect automatically» или конкретный язык; ручной выбор действует даже при выключенной подсветке и только для этого файла.

### Какие языки и форматы поддерживаются

Поддерживаются UCI-конфиги OpenWrt, Kconfig (`.config`, `Kconfig`), U-Boot (`uEnv.txt`, `boot.cmd`), Yocto (`.bb`, `.bbappend`, `.inc`), Linker scripts (`.ld`, `.lds`), ifupdown (`/etc/network/interfaces`, `/etc/network/interfaces.d/*`), dnsmasq (`dnsmasq.conf`, `/etc/dnsmasq.d/*`), hostapd (`hostapd.conf`, `/etc/hostapd/*.conf`, `/var/run/hostapd-*.conf`), WireGuard (`/etc/wireguard/*.conf`, `wg0.conf`), udev (`/etc/udev/rules.d/*.rules`, `/usr/lib/udev/rules.d/*.rules`, `udev.conf`), nftables (`/etc/nftables.conf`, `/etc/nftables.d/*.conf`, `*.nft`), modprobe.d (`/etc/modprobe.d/*.conf`, `/usr/lib/modprobe.d/*.conf`, `modprobe.conf`), logrotate (`/etc/logrotate.conf`, `/etc/logrotate.d/*`), sysctl (`/etc/sysctl.conf`, `/etc/sysctl.d/*.conf`, `/usr/lib/sysctl.d/*.conf`), PAM (`/etc/pam.conf`, `/etc/pam.d/*`), Samba (`smb.conf`), Postfix (`main.cf`, `master.cf`, `/etc/postfix/*.cf`), OpenVPN (`*.ovpn`, `/etc/openvpn/*.conf`, `openvpn.conf`), Netplan (`/etc/netplan/*.yaml`, `/run/netplan/*.yaml`), cloud-init (`cloud-config`, `/etc/cloud/cloud.cfg`, `/etc/cloud/cloud.cfg.d/*.cfg`, `#cloud-config`), Prometheus (`prometheus.yml`, `/etc/prometheus/*.yml`), Alertmanager (`alertmanager.yml`, `/etc/alertmanager/*.yml`), MongoDB (`mongod.conf`, `mongos.conf`, `/etc/mongodb/*.conf`), Elasticsearch (`elasticsearch.yml`, `/etc/elasticsearch/*.yml`), shell, Makefile, Meson (`meson.build`, `meson.options`, `meson_options.txt`), HCL (`.tf`, `.tfvars`, `.hcl`, `.nomad`), Starlark (`BUILD`, `BUILD.bazel`, `WORKSPACE`, `WORKSPACE.bazel`, `MODULE.bazel`, `*.bzl`, `*.star`), Nix (`*.nix`, `flake.nix`, `default.nix`, `shell.nix`), Fish (`.fish`), Batch (`.bat`, `.cmd`), Lua, JSON (в том числе с комментариями), Python, YAML, C, C++, C#, Java, Kotlin, Scala, Groovy, Go, Rust, Verilog, VHDL, Swift, Dart, JavaScript, TypeScript, PHP, CSS, Protobuf, Device Tree, AWK, Tcl, Assembly, PowerShell, TOML, INI/conf, SQL, HTML/XML, Markdown и diff.

### Особенности по языкам

Ниже — что именно подсвечивается и по каким именам файлов язык определяется.

#### Конфигурационные файлы Linux и сервисов

- **ifupdown** (`/etc/network/interfaces`, `/etc/network/interfaces.d/*`) подсвечивается как Config со стансами `auto`, `iface`, `allow-hotplug`, `source` и опциями (`address`, `netmask`, `gateway`, `dns-nameservers`, `bridge_ports`, `bond-slaves`, `wpa-ssid`, `pre-up`/`post-up`), а семейства адресов и методы (`inet`, `inet6`, `static`, `dhcp`, `loopback`) выделяются цветом ключевых слов; комментарии — `#`.
- **dnsmasq** (`dnsmasq.conf`, `/etc/dnsmasq.d/*`) подсвечивается как Config с известными опциями (`server`, `address`, `interface`, `cache-size`, `dhcp-range`, `dhcp-host`, `dhcp-option`, `log-queries`, `conf-dir`); опции без значения (`bogus-priv`, `no-resolv`, `bind-interfaces`, `dhcp-authoritative`) и типичные значения (`static`, `tag`, `ra-names`, `slaac`) тоже выделяются цветом ключевых слов, а комментарии — `#`.
- **hostapd** (`hostapd.conf`, `/etc/hostapd/*.conf`, `/var/run/hostapd-*.conf`) подсвечивается как Config с известными опциями (`interface`, `driver`, `ssid`, `hw_mode`, `channel`, `wpa`, `wpa_key_mgmt`, `wpa_passphrase`, `bridge`, `ieee80211n`); режимы `a`/`b`/`g`/`ad`, наборы WPA (`WPA-PSK`, `SAE`, `OWE`, `DPP`) и шифры (`CCMP`, `TKIP`, `GCMP`) выделяются цветом ключевых слов; комментарии — `#`.
- **WireGuard** (`/etc/wireguard/*.conf`, `wg0.conf`) подсвечивается как Config с секциями `[Interface]` и `[Peer]` и известными ключами (`PrivateKey`, `Address`, `ListenPort`, `PublicKey`, `PresharedKey`, `AllowedIPs`, `Endpoint`, `PersistentKeepalive`); значения `auto`, `main`, `default` и `off` выделяются цветом ключевых слов, а ключи читаются без учёта регистра, как их читает wg-quick; комментарии — `#`.
- **udev** (`/etc/udev/rules.d/*.rules`, `/usr/lib/udev/rules.d/*.rules`, `/run/udev/rules.d/*.rules`, `udev.conf`) подсвечивается как Config с ключами правил (`ACTION`, `SUBSYSTEM`, `KERNEL`, `ATTR`, `ENV`, `SYMLINK`, `TAG`, `PROGRAM`, `RESULT`, `RUN`, `OPTIONS`, `GOTO`), которые выделяются в любом месте строки, ведь правило — это список пар `КЛЮЧ==значение` через запятую; действия (`add`, `remove`, `change`) и опции (`db_persist`, `last_rule`, `nowatch`) тоже ключевые слова, а `#` комментарии.
- **nftables** (`/etc/nftables.conf`, `/etc/sysconfig/nftables.conf`, `/etc/nftables.d/*.conf`, `*.nft`) подсвечивается как Config с командами (`flush`, `table`, `chain`, `set`, `add`, `delete`), выражениями и действиями (`accept`, `drop`, `reject`, `masquerade`, `snat`, `dnat`, `log`, `counter`), протоколами (`ip`, `ip6`, `tcp`, `udp`, `ct`), ключами сопоставления (`saddr`, `daddr`, `dport`, `iifname`, `hook`, `priority`, `policy`) и значениями (`established`, `related`, `input`, `forward`, `srcnat`, `ipv4_addr`); комментарии — `#`.
- **modprobe.d** (`/etc/modprobe.d/*.conf`, `/usr/lib/modprobe.d/*.conf`, `/run/modprobe.d/*.conf`, `modprobe.conf`) подсвечивается как Config с директивами (`alias`, `blacklist`, `options`, `install`, `remove`, `softdep`, `weakdep`, `include`); стадии `pre`/`post` в `softdep` и `off` в `alias` выделяются как ключевые слова; комментарии — `#`.
- **logrotate** (`/etc/logrotate.conf`, `/etc/logrotate.d/*`) подсвечивается как Config с директивами (`rotate`, `create`, `include`, `size`, `maxsize`, `su`, `olddir`, `dateformat`), а директивы без значения (`daily`, `weekly`, `monthly`, `compress`, `delaycompress`, `missingok`, `notifempty`, `sharedscripts`, `postrotate`, `endscript`) выделяются цветом ключевых слов; блоки правил в `{ }` сворачиваются, комментарии — `#`.
- **sysctl** (`/etc/sysctl.conf`, `/etc/sysctl.d/*.conf`, `/usr/lib/sysctl.d/*.conf`, `/run/sysctl.d/*.conf`) подсвечивается как Config с известными параметрами ядра (`net.ipv4.ip_forward`, `net.ipv4.tcp_syncookies`, `vm.swappiness`, `fs.file-max`, `kernel.sysrq`); типичные значения (`bbr`, `fq_codel`, `default`, `all`) и числа выделяются, а неизвестный параметр остаётся обычным ключом; комментарии — `#`.
- **PAM** (`/etc/pam.conf`, `/etc/pam.d/*`) подсвечивается как Config с группами управления (`auth`, `account`, `password`, `session`), флагами контроля (`required`, `requisite`, `sufficient`, `optional`, `include`) и распространёнными модулями (`pam_unix.so`, `pam_env.so`, `pam_systemd.so`, `pam_pwquality.so`); аргументы модулей (`nullok`, `try_first_pass`, `retry`, `minlen`, `remember`) и слова в квадратных скобках (`[success=1 default=ignore]`) тоже выделяются, комментарии — `#`.
- **Samba** (`smb.conf`) подсвечивается как Config с секциями `[global]` и `[share]` и параметрами (`workgroup`, `security`, `map to guest`, `server min protocol`, `passdb backend`, `path`, `read only`, `create mask`, `vfs objects`); параметры из нескольких слов выделяются целиком, значения (`user`, `tdbsam`, `SMB2`, `recycle`) тоже ключевые слова, а имена секций и параметров читаются без учёта регистра; комментарии — `#`, и строки, начинающиеся с `;`, тоже считаются комментариями.
- **Postfix** (`/etc/postfix/main.cf`, `/etc/postfix/master.cf`, другие `.cf` из `/etc/postfix`) подсвечивается как Config с параметрами `main.cf` (`myhostname`, `mydestination`, `mynetworks`, `relayhost`, `smtpd_tls_security_level`, `smtpd_relay_restrictions`, `message_size_limit`, `compatibility_level`); в `master.cf` выделяются имена служб (`smtp`, `submission`, `pickup`, `cleanup`, `qmgr`), типы (`inet`, `unix`), флаги `y`/`n`, типы таблиц (`hash`, `lmdb`) и ограничения (`permit_mynetworks`, `reject_unauth_destination`), поэтому колонки читаются; неизвестный параметр остаётся обычным ключом, комментарии — `#`.
- **OpenVPN** (`*.ovpn`, `/etc/openvpn/*.conf`, `openvpn.conf`) подсвечивается как Config с опциями профиля (`port`, `proto`, `dev`, `ca`, `cert`, `key`, `server`, `push`, `keepalive`, `cipher`, `data-ciphers`, `auth`, `remote-cert-tls`, `tls-version-min`); значения (`udp`, `tcp`, `tun`, `tap`, `server`, `client`, `AES-256-GCM`, `CHACHA20-POLY1305`, `SHA256`, `infinite`) тоже ключевые слова, а директивы без значения (`client`, `nobind`, `persist-key`, `persist-tun`) выделяются сами по себе; комментарии — `#` и `;`, строки с ними в начале считаются комментариями.
- **Netplan** (`/etc/netplan/*.yaml`, `/etc/netplan/*.yml`, `/run/netplan/*.yaml`) подсвечивается как YAML с ключами сетевой конфигурации (`network`, `version`, `renderer`, `ethernets`, `wifis`, `bridges`, `bonds`, `vlans`, `dhcp4`, `addresses`, `gateway4`, `nameservers`, `routes`, `access-points`, `auth`, `parameters`); значения (`networkd`, `NetworkManager`, `openvswitch`, `static`, `default`, `active-backup`, `psk`, `eap`) тоже ключевые слова, а имена интерфейсов остаются обычными ключами; блоки сворачиваются, комментарии — `#`.
- **cloud-init** (`cloud-config`, `/etc/cloud/cloud.cfg`, `/etc/cloud/cloud.cfg.d/*.cfg`, `/usr/lib/cloud/*.cfg`, `user-data`; файл с первой строкой `#cloud-config` определяется по ней, как бы он ни назывался) подсвечивается как YAML с модулями (`version`, `hostname`, `users`, `ssh_authorized_keys`, `chpasswd`, `package_update`, `packages`, `write_files`, `owner`, `permissions`, `runcmd`, `bootcmd`, `power_state`, `datasource`); значения (`reboot`, `poweroff`, `always`, `per-instance`, `ext4`, `xfs`, `dhcp`, `cloud-config`) тоже ключевые слова, блоки сворачиваются, комментарии — `#`.
- **Prometheus** (`prometheus.yml`, `prometheus.yaml`, `/etc/prometheus/*.yml`) подсвечивается как YAML с настройками (`global`, `scrape_interval`, `scrape_configs`, `job_name`, `static_configs`, `targets`, `labels`, `relabel_configs`, `source_labels`, `target_label`, `regex`, `alerting`, `alertmanagers`, `remote_write`, `queue_config`, `tls_config`, `authorization`) и правилами алертов (`groups`, `name`, `rules`, `alert`, `expr`, `for`, `annotations`, `summary`, `runbook_url`); значения (`http`, `https`, `Bearer`, `replace`, `keep`, `drop`, `labelmap`, `pod`, `service`, `node`, `ingress`) тоже ключевые слова, блоки сворачиваются, комментарии — `#`.
- **Alertmanager** (`alertmanager.yml`, `alertmanager.yaml`, `/etc/alertmanager/*.yml`) подсвечивается как YAML с деревом маршрутов и получателями (`global`, `resolve_timeout`, `route`, `receiver`, `group_by`, `group_wait`, `repeat_interval`, `matchers`, `routes`, `receivers`, `name`, `email_configs`, `slack_configs`, `api_url`, `channel`, `send_resolved`, `inhibit_rules`, `source_matchers`, `target_matchers`, `equal`, `mute_time_intervals`, `time_intervals`); значения (`http`, `https`, `Bearer`, `HTML`, `Markdown`, дни недели) тоже ключевые слова, блоки сворачиваются, комментарии — `#`.
- **MongoDB** (`mongod.conf`, `mongos.conf`, `mongodb.conf`, `/etc/mongodb/*.conf`) подсвечивается как YAML с настройками (`systemLog`, `destination`, `path`, `logAppend`, `storage`, `dbPath`, `journal`, `engine`, `wiredTiger`, `cacheSizeGB`, `blockCompressor`, `net`, `port`, `bindIp`, `tls`, `mode`, `certificateKeyFile`, `security`, `authorization`, `keyFile`, `operationProfiling`, `slowOpThresholdMs`, `replication`, `replSetName`, `sharding`, `clusterRole`, `auditLog`, `setParameter`); значения (`file`, `syslog`, `JSON`, `BSON`, `enabled`, `disabled`, `requireTLS`, `allowTLS`, `wiredTiger`, `inMemory`, `configsvr`, `shardsvr`, `slowOp`, `SCRAM-SHA-256`, `snappy`) тоже ключевые слова, блоки сворачиваются, комментарии — `#`.
- **Elasticsearch** (`elasticsearch.yml`, `elasticsearch.yaml`, `/etc/elasticsearch/*.yml`) подсвечивается как YAML с настройками (`cluster.name`, `cluster.initial_master_nodes`, `node.name`, `node.roles`, `path.data`, `path.logs`, `network.host`, `http.port`, `discovery.type`, `discovery.seed_hosts`, `bootstrap.memory_lock`, `xpack.security.enabled`, `xpack.security.transport.ssl.*`, `xpack.security.http.ssl.*`, `xpack.ml.enabled`, `action.destructive_requires_name`, `indices.query.bool.max_clause_count`, `thread_pool.write.queue_size`); значения (`single-node`, `master`, `data_hot`, `ingest`, `certificate`, `full`, `native`, `ldap`, `all`, `primaries`, `basic`, `platinum`) тоже ключевые слова, блоки сворачиваются, комментарии — `#`.

#### Встраиваемые системы, ядро и загрузчик

- **Device Tree:** подсвечиваются директивы `/dts-v1/`, `/include/`, `/delete-node/`, `/delete-property/`, `/omit-if-no-ref/`, `#include`, ссылки на метки `&label`, метки узлов, свойства с `#` (`#address-cells`, `#gpio-cells`) и стандартные свойства вроде `compatible`, `reg`, `interrupt-parent`, `pinctrl-names`, `gpio-controller`. В overlays (`.dtso`) дополнительно подсвечиваются `/plugin/`, `/bits/`, узлы `__overlay__`, `__overrides__`, `__symbols__`, `__fixups__`, `__local_fixups__` и свойства `target`, `target-path`.
- **Kconfig** (`.config`, `Kconfig`) — конфигурация ядра Linux и OpenWrt: подсвечиваются директивы (`config`, `menuconfig`, `menu`/`endmenu`, `choice`/`endchoice`, `comment`, `mainmenu`), зависимости и атрибуты (`depends on`, `select`, `imply`, `default`, `prompt`, `range`, `visible`), типы (`bool`, `tristate`, `string`, `int`, `hex` и `def_bool`, `def_tristate`, `def_string`, `def_int`, `def_hex`), условия `if`/`endif`, подключение других файлов (`source`, `rsource`, `osource`, `orsource`) и ссылки `$(NAME)`; значения `y`/`m`/`n` тоже выделяются, текст блока `help` остаётся обычным, а комментарии начинаются с `#`; `Ctrl+/` вставляет `#`.
- **U-Boot** (`uEnv.txt`, `boot.cmd`) — окружение и скрипты загрузчика: подсвечиваются команды (`setenv`, `saveenv`, `run`, `bootm`, `bootz`, `booti`, `bootefi`, `bootmenu`, `bootflow`, `tftpboot`, `wget`, `fatload`, `ext4load`, `mmc`, `nvme`, `pci`, `dhcp`, `ping`, `sntp`, `cat`, `bdinfo`, `fdt` и другие), переменные `${name}`, числа и комментарии `#`; `Ctrl+/` вставляет `#`.
- **Yocto** (`.bb`, `.bbappend`, `.bbclass`, `.inc`, `layer.conf`) — рецепты и классы BitBake: подсвечиваются переменные (`SUMMARY`, `SRC_URI`, `DEPENDS`, `BB_NUMBER_THREADS`, `BB_CONF_FRAGMENT_SUMMARY`, `OE_FRAGMENTS` и другие), директивы (`inherit`, `require`, `include`, `addtask`, `addhandler`, `addpylib`, `addfragments`), задачи `do_*`, ссылки `${NAME}`, строки, числа и комментарии `#`; `Ctrl+/` вставляет `#`.
- **Linker scripts** (`.ld`, `.lds`, `.ld.in`) — сценарии компоновки: подсвечиваются команды (`SECTIONS`, `MEMORY`, `OUTPUT_FORMAT`, `ENTRY`, `AT`, `ALIGN`, `VERSION`, `NOCROSSREFS`, `NOCROSSREFS_TO` и другие), имена секций и символов, числа, строки в кавычках и комментарии `/* */`; `Ctrl+/` вставляет `/* */`.
- **Assembly** определяется по расширениям `.asm`, `.s` и `.nasm`: подсвечиваются метки (`_start:`, `.loop:`, числовые `1:`), директивы ассемблера (`.text`, `.globl`, `%define`), инструкции x86/x86-64, ARM/AArch64, MIPS и RISC-V и регистры (`%eax`, `rax`, `r0`, `x0`); комментарии — `;`, `#` в начале строки, `@` после пробела, а также `//` и `/* */`.
- **Verilog и SystemVerilog** определяются по расширениям `.v`, `.vh`, `.sv` и `.svh`: подсвечиваются ключевые слова, директивы с обратной кавычкой (`timescale`, `define`, `include`, `ifdef`), системные задачи и функции (`$display`, `$finish`, `$random`), комментарии `//` и `/* */`, а апостроф в литералах вида `4'b1010` не считается строкой.
- **VHDL** определяется по `.vhd` и `.vhdl`: ключевые слова не зависят от регистра, комментарии — `--`, а апостроф в атрибутах (`clk'event`) и символах (`'0'`) не считается строкой.

#### Сборка, скрипты и оболочки

- **Bash** (`.sh`, `.bash`, `.zsh`, `.ksh`, `.bashrc`, `.profile`, `rc.local`, а также `#!` с bash или sh) — командная оболочка: подсвечиваются комментарии `#`, строки в одинарных и двойных кавычках (в том числе многострочные), ANSI-C строки `$'...'` с экранированными кавычками и локализованные строки `$"..."`, переменные `$name`, `${name}`, `$1`, `$?`, `$#`, `$!`, здесь-документы `<<EOF` (в том числе `<<-EOF` с отступами и `<<'EOF'` без подстановок), числа, зарезервированные слова и встроенные команды (`if`/`then`/`elif`/`else`/`fi`, `for`/`while`/`until`/`do`/`done`, `case`/`esac`, `select`, `function`, `cd`, `echo`, `printf`, `read`, `mapfile`, `shopt`, `test`, `type`, `wait`, `export`, `local`, `unset`, `shift`, `trap` и другие), присваивания `NAME=value` и `NAME+=value`, а блоки `if`/`for`/`while`/`case` и `{ }` сворачиваются; `Ctrl+/` вставляет `#`.
- **PowerShell** определяется по расширениям `.ps1`, `.psm1`, `.psd1`, `.ps1xml`, `.pssc` и `.psrc`, а также по shebang `pwsh`/`powershell`: подсвечиваются переменные (`$name`, `${name}`, `$env:PATH`, `$1`, splatting `@args`), команды вида `Verb-Noun` (`Get-ChildItem`, `Where-Object`, включая команды установленных модулей), операторы (`-eq`, `-not`, `-replace`), here-strings `@" … "@` и `@' … '@`, обычные строки с экранированием обратной кавычкой; комментарии — `#` и `<# … #>`.
- **Makefile** (`Makefile`, `GNUmakefile`, `BSDmakefile`, `*.mk`, `Makefile.am`) — сборочные файлы make: подсвечиваются директивы (`include`, `-include`, `sinclude`, `export`, `unexport`, `override`, `vpath`, `undefine`, `ifeq`/`ifneq`/`ifdef`/`ifndef`, `else`, `endif`, `define`/`endef`), встроенные функции GNU make внутри `$(...)` и `${...}` (`wildcard`, `patsubst`, `subst`, `foreach`, `call`, `shell`, `info`, `error` и другие, в том числе вложенные вызовы), переменные (`NAME`, `NAME:=`, `NAME+=`, `NAME?=`, `NAME!=`), автоматические переменные (`$@`, `$<`, `$^`, `$?`, `$*`, `$%`, `$+`, `$|`), цели правил, строки и комментарии `#`; блоки `ifeq…endif`, `define…endef` и правила «цель + рецепт» сворачиваются; `Ctrl+/` вставляет `#`.
- **Meson** (`meson.build`, `meson.options`, `meson_options.txt`) подсвечивается как язык сборки: ключевые слова `if`, `elif`, `else`, `endif`, `foreach`, `endforeach`, `break`, `continue`, `and`, `or`, `not`, `in`, `true`, `false`, функции `project`, `executable`, `library`, `shared_library`, `static_library`, `dependency`, `declare_dependency`, `configure_file`, `custom_target`, `files`, `include_directories`, `subdir`, `subproject`, `summary`, `message`, `warning`, `error`, `install_data`, `install_headers`, `test`, `benchmark`, `get_option`, `run_command`, `find_program`, `import`, `set_variable`, `get_variable` и методы объектов (`found`, `full_path`, `get`, `format`, `contains`, `split`, `join`, `to_string`, `system`, `cpu_family`, `get_compiler`, `has_function`, `get_supported_arguments`), а встроенные объекты `meson`, `host_machine`, `build_machine`, `target_machine` выделяются как переменные; комментарии — `#`.
- **Starlark** (`BUILD`, `BUILD.bazel`, `WORKSPACE`, `WORKSPACE.bazel`, `WORKSPACE.bzlmod`, `MODULE.bazel`, `REPO.bazel`, `TARGETS`, `BUCK`, `*.bzl`, `*.star`) — язык сборки Bazel и Buck, похожий на Python: подсвечиваются комментарии `#`, строки (включая тройные кавычки), числа, ключевые слова (`def`, `if`/`elif`/`else`, `for`, `in`, `lambda`, `load`, `return`, `True`/`False`/`None`), функции и правила Bazel (`package`, `glob`, `select`, `cc_library`, `py_binary`, `java_test`, `genrule`, `depset`, `struct`, `fail`, ...), а блоки с отступом (`def`, `if`, `for`) сворачиваются; `Ctrl+/` вставляет `#`.
- **Nix** (`.nix`, `flake.nix`, `default.nix`, `shell.nix`) — язык выражений Nix и NixOS: подсвечиваются ключевые слова (`let`, `in`, `with`, `rec`, `inherit`, `assert`, `if`/`then`/`else`) и литералы `true`/`false`/`null`, встроенные функции (`import`, `derivation`, `fetchTarball`, `map`, `filter`, `attrNames`, `concatStringsSep`, `foldl'`, ...), объект `builtins`, комментарии `#` и `/* */`, строки `"..."` с интерполяцией `${...}` и многострочные строки `''...''` (внутри них `#`, кавычки и код остаются текстом), пути `./default.nix`, `../lib`, `~/x`, `/nix/store/...` и `<nixpkgs>`, числа; наборы атрибутов `{ }` сворачиваются; `Ctrl+/` вставляет `#`.
- **HCL** (`.tf`, `.tfvars`, `.hcl`, `.nomad`) — язык Terraform и Nomad: подсвечиваются ключевые слова и блоки (`terraform`, `resource`, `data`, `variable`, `module`, `output`, `locals`, `job`, `task`), мета-аргументы (`for_each`, `count`, `depends_on`, `lifecycle`), встроенные функции (`file`, `templatefile`, `jsonencode`, `merge`, `lookup`, `cidrsubnet`) и объекты `var`, `local`, `path`, `each`, `self`; строки, числа, комментарии `#`, `//` и `/* */`, heredoc `<<EOF` и `<<-EOF` (строки до терминатора не подсвечиваются как код) и сворачивание блоков `{ }`; `Ctrl+/` вставляет `#`.
- **Dockerfile** (`Dockerfile`, `Containerfile`, `Dockerfile.*`, `*.dockerfile`) — файлы сборки образов: подсвечиваются инструкции в начале строки без учёта регистра (`FROM`, `RUN`, `CMD`, `LABEL`, `MAINTAINER`, `EXPOSE`, `ENV`, `ADD`, `COPY`, `ENTRYPOINT`, `VOLUME`, `USER`, `WORKDIR`, `ARG`, `ONBUILD`, `STOPSIGNAL`, `HEALTHCHECK`, `SHELL`), переменные `$NAME` и `${NAME}` (в том числе в `FROM`, `ENV` и `ARG`), here-документы `<<EOF` и `<<-EOF`, после которых строки до терминатора остаются текстом (в них `#` и `$NAME` не подсвечиваются), строки и комментарии `#`; `Ctrl+/` вставляет `#`.
- **Fish** (`.fish`) — оболочка fish: подсвечиваются комментарии `#`, строки в одинарных и двойных кавычках (в том числе многострочные), переменные `$files`, `$argv`, `$status`, числа, ключевые слова и встроенные команды (`if`/`else`/`end`, `for`/`in`, `while`, `switch`/`case`, `function`, `begin`, `set`, `test`, `string`, `math`, `source`, `contains`, `emit`, `abbr` и другие), а блоки `if`/`for`/`while`/`switch`/`function`/`begin` … `end` сворачиваются; `Ctrl+/` вставляет `#`.
- **Batch** (`.bat`, `.cmd`) — командные файлы Windows: подсвечиваются команды и ключевые слова без учёта регистра (`echo`, `set`, `setlocal`, `if`, `for`, `in`, `do`, `goto`, `call`, `exit`, `copy`, `move`, `robocopy`, `powershell` и другие), комментарии `REM` и `::` в начале строки, строки в кавычках, переменные `%NAME%`, `%1`, `%*`, `%%i`, `%~dp0`, `!NAME!`, числа и метки `:name` (в том числе цель `goto`); `Ctrl+/` вставляет `REM `.

#### Данные и разметка

- **TOML** определяется по расширению `.toml`, по именам `Cargo.lock`, `Pipfile`, `poetry.lock`, `uv.lock` и `pdm.lock`, а также по файлам `/etc/containers/*.conf`: подсвечиваются таблицы `[table]` и `[[array]]`, ключи (в том числе точечные `a.b` и в кавычках), строки `"…"` и `'…'`, многострочные `"""…"""` и `'''…'''`, числа, даты и `true`/`false`; комментарии — `#`, а массивы и inline-таблицы сворачиваются.
- **YAML** (`.yaml`, `.yml`, а также YAML с известными ключами Kubernetes, Compose, Ansible, Netplan, cloud-init, Prometheus и других форматов) — формат конфигурации: подсвечиваются ключи `key:`, строки и комментарии `#`, маркеры документов `---` и `...`, якоря `&name`, ссылки `*alias` и ключ слияния `<<:`; блоки сворачиваются по отступам, в том числе `key: &name` и `- &name`, за которыми следует вложенный узел; `Ctrl+/` вставляет `#`.
- **SQL** (`*.sql`) — запросы и DDL: подсвечиваются ключевые слова ANSI, диалектов PostgreSQL (`jsonb`, `timestamptz`, `ilike`, `returning`, `lateral`, `jsonb_agg`), MySQL/MariaDB (`auto_increment`, `unsigned`, `longtext`, `engine`, `on duplicate key update`) и SQLite (`pragma`, `autoincrement`, `without rowid`, `insert or replace`), а также блоки PL/pgSQL (`declare`, `raise notice`, `exception`, `others`).
- **Markdown** (`.md`, `.markdown`, `.mdown`, `.mkd`, `.mkdn`, `.mdwn`) подсвечивается как разметка: заголовки `#`/`##` и подчёркивания `===`, списки (`-`, `*`, `1.`) с отметками `[ ]`/`[x]`, цитаты `>`, горизонтальные линии, жирный `**текст**`, курсив `*текст*`/`_текст_`, зачёркивание `~~текст~~`, встроенный код (`код`), ссылки и картинки `[текст](адрес)`, автоссылки и голые URL, таблицы с `|`; блоки кода, окружённые тремя обратными кавычками или тильдами, окрашиваются целиком и не разбираются внутри, а HTML-комментарии `<!-- -->` могут занимать несколько строк; `Ctrl+/` вставляет `<!-- -->`.
- **HTML/XML:** содержимое `<script>` подсвечивается как JavaScript, а `<style>` — как CSS, включая комментарии, шаблонные строки и многострочные конструкции; остальной текст и атрибуты тегов остаются разметкой.

## Автодополнение

Пока файл подсвечивается, редактор подсказывает слова — ключевые слова выбранного языка, стандартные функции языка (API-символы, см. ниже) и идентификаторы, уже встречающиеся в файле.

- **Как включить.** Список открывается по `Ctrl+Space`; включается и выключается в Settings → Editor Settings (флажок «Offer completions while editing»), там же флажок «Open the completion list automatically while typing» — тогда список появляется сам после двух букв слова.
- **Как пользоваться.** Пока список открыт, набранные буквы сужают его, `↑`/`↓` выбирают слово, `Tab`, `Enter` или `Space` подставляют его вместо набираемого, `Esc` закрывает.
- **Для каких языков.** Поддерживаются все языки с подсветкой: C, C++, C#, Java, Kotlin, Scala, Groovy, Go, Rust, Verilog, VHDL, Swift, Dart, JavaScript, TypeScript, PHP, CSS, Protobuf, Device Tree, AWK, Tcl, Assembly, PowerShell, Python, Lua, Bash, Fish, Batch, Makefile, Meson, HCL, Markdown, Starlark, Nix, SQL, JSON, YAML, TOML, INI/conf, UCI, Ruby, Perl, CMake, Dockerfile, Kconfig, U-Boot, Yocto, linker scripts, crontab, fstab, sudoers, PostgreSQL, MySQL/MariaDB, Redis, HAProxy, Apache httpd, systemd-networkd, ifupdown, dnsmasq, hostapd, WireGuard, udev, nftables, modprobe.d, logrotate, sysctl, PAM, Samba, Postfix, OpenVPN, Netplan, cloud-init, Prometheus, Alertmanager, MongoDB, Elasticsearch, Kubernetes/Helm, Docker Compose и Ansible; у Device Tree в списке есть стандартные свойства и общие имена узлов, в HTML/XML, Markdown и в обычном тексте предлагаются слова из самого файла.

## База символов API

Редактор знает отдельный набор стандартных функций языка (Python builtins, функции C, встроенные команды оболочки, стандартные функции Lua и SQL, стандартные библиотеки Go и Rust, системные задачи Verilog и пакеты IEEE VHDL), которые редактор знает, даже если они не определены в открытом файле. В списке автодополнения такой символ выделен жирным и рядом с ним показано краткое описание, а при вызове (`print(`) подсказка параметров берёт его сигнатуру.

- **Откуда берётся.** Набор поставляется в `Completion/ApiSymbols.xml` и вшит в сборку; файл `ApiSymbols.xml` рядом с `SmarTTY.exe` заменяет встроенный набор, поэтому его можно расширить без пересборки.
- **Как включить.** Включается и выключается флажком «Offer the standard functions of the language (API symbols)» в Settings → Editor Settings; когда он выключен, файл не читается.

## Подсказка параметров

Когда каретка стоит внутри вызова функции, редактор показывает её параметры и выделяет тот, который набирается сейчас. Сигнатура берётся из определения в самом файле, а если функции там нет — из базы символов API (например, `print(`, `printf(`, `math.sqrt(`, `fmt.Println(`, `std::fs::read_to_string(`).

- **Когда появляется.** Подсказка появляется после `(`, обновляется при вводе запятых и при перемещении каретки, а при `)` или `Esc` закрывается; включается и выключается тем же флажком «Offer completions while editing».
- **Откуда берутся сигнатуры.** Сигнатуры читаются из самого файла: `def f(...)` в Python, `function f(...)` и `local function f(...)` в Lua, `def`/`sub`/`function`/`fn` и `name(...) {` в shell и скриптах, а также определения вида `int f(int x)` в C-подобных языках. Запятые внутри вложенных вызовов, строк и скобок не считаются.
